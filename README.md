# Road Tales of Middle-earth

An interactive, voice-first storytelling game for long car journeys, played with Claude.

You talk, Claude tells the story. Every so often it stops and asks what the hero does next, and you decide. It's a bit like the old Fighting Fantasy gamebooks, but spoken, and the story can go anywhere you take it. It's a lot more fun than another podcast.

The stories here are set in the world of J.R.R. Tolkien, mostly in the gaps the books leave open: what happened in the far East, who the Elves were who never went West, where the two Blue Wizards went. Nothing here tries to replace the canon. It just plays in the spaces around it.

## How to play

1. Open the Claude app (voice mode works best when you're driving).
2. Give Claude the rules in [CLAUDE.md](CLAUDE.md). If you use Claude Code or a Claude Project, put this repo in it and the file is picked up automatically. Otherwise paste it in at the start of the chat.
3. Say what you fancy: "carry on with Rúmil", "a new story about the Dwarves of the Red Mountains", "recap where we got to".
4. Steer. Answer the questions, or interrupt and change things. If a bit doesn't feel right, say so and Claude retells it.

Keep your eyes on the road. This is meant to be played by voice, hands free.

3. [The Mirror in the Hills](stories/03-the-blue-wizards-and-the-mirror.md): Pallando, a fisherman's son and a blind Elf break Sauron's first mirror in the East.

## Make it your own

Everything here is meant to be taken and changed.

- Pick up any story and take it somewhere else.
- Start a brand new one. The Easterlings, the Dwarves of the far East, the Entwives, Harad, anywhere.
- Rewrite the rules in CLAUDE.md. Want proper dice rolls, stats and inventory like a real gamebook? Add them. Want it gentler for kids in the back seat? Say so in the rules.
- Use a different world entirely. The rules work for any setting; swap the Tolkien bits out.

If you play a story you like, a pull request with it is very welcome.

## Saving as you go

The rules ask Claude to write each story into this repo and commit it as you go, so you can stop at a service station and pick it up again next trip. Tell Claude to "save the story" any time to be sure.
